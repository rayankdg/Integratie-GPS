# Integratie-GPS

A small project for GPS integration and demo documentation.

## Tutorial 1: Save repository changes to GitHub

1. Stage changed files:
   ```bash
git add .
```
2. Commit your work:
   ```bash
git commit -m "Save README and update docs"
```
3. Push to the remote branch:
   ```bash
git push origin patch-2
```

This saves your changes to GitHub and updates the current pull request.

## Tutorial 2: Publish a simple site with GitHub Pages

1. Add a site file such as `index.html` or create a `docs/` folder.
2. Open the repository settings on GitHub.
3. Enable GitHub Pages and select the branch and folder to publish from.
4. Wait for GitHub to build and publish the site.

Your site will be available at a URL like `https://<username>.github.io/Integratie-GPS`.
